# controle-de-estoque
**Controle de Estoque**: é um projeto feito em C, que permite a criação, edição e exclusão de produtos, em um arquivo de texto, através do console.

Tecnologias:<br> 
    > C

Conceitos abordados:<br>
    > Entrada e saída de dados;<br>
    > Ponteiros;<br>
    > Arrays;<br>
    > Funções;<br>
    > Structs;<br>
    > Files;<br>
    > Errors;<br>
    > Encapsulamento.
